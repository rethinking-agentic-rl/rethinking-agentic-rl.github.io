# Rethinking Agentic RL

Project website for *What Does Multi-Turn Reinforcement Learning Really Improve in LLM Agents?*

Static HTML, CSS, and JavaScript; no build step required.

## GitHub Pages

Repository: `rethinking-agentic-rl/rethinking-agentic-rl.github.io`

In **Settings → Pages**, choose **Deploy from a branch**, branch **main**, folder **/(root)**.

Intended website: https://rethinking-agentic-rl.github.io/

## Resource links

Set the paper PDF and research code repository URLs in `assets/js/site-config.js`. Empty values keep the current Coming soon buttons.

## Local preview

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```
